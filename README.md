# Site du collectif ARTI/CHÔ, version 2

Refonte du mécanisme de mise à jour de `collectifarticho.com`, pour que les membres
de la SCOP puissent modifier le site seul·es, depuis un formulaire web, sans
toucher au code et sans abonnement.

- `ROADMAP.md` : le besoin, les décisions, le plan ; son bandeau dit où on en est.
- `CHANGELOG.md` : ce qui a été fait, version par version.
- `CLAUDE.md` : contexte technique complet, y compris sur l'ancien site.
- `docs/mode-emploi.md` : pour les membres qui modifient le site.

Site en construction : https://collectif-articho.github.io/ ; administration :
https://collectif-articho.github.io/admin/.

Le site actuellement en ligne est dans le dossier voisin `../collectif-articho/`.
Ce dépôt est `collectif-articho/collectif-articho.github.io` ; il est publié à
chaque push sur `main`.
