Option B : le bilan

Ce qui est bien

  • 0 € : GitHub héberge gratuitement, comme aujourd'hui
  • Rien à entretenir, pas de serveur
  • Le site garde exactement son design
  • Des formulaires taillés pour nos fiches : impossible d'oublier un champ
  • Des adresses de pages stables, même quand on renomme un projet
  • Nos contenus restent des fichiers ordinaires : on peut changer d'outil sans rien perdre

Ce qui coince

  • Revenir à une ancienne version passe par GitHub, c'est moins simple que dans WordPress
  • Un outil jeune, porté par une petite équipe
  • On modifie le contenu, pas la mise en page (c'est voulu)
  • La connexion sans compte GitHub reste à confirmer en test
Le point faible principal : annuler une modification. Corriger, c'est facile, on rouvre la fiche. Revenir à une version d'il y a trois mois se fait depuis GitHub. Tout est conservé, mais c'est moins confortable que WordPress. À regarder au prototype, comme la connexion par e-mail.
